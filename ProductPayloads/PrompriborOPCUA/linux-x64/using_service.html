👤 Инструкция для пользователей - Установка и настройка службы Prompribor OPC UA

💡 Эта инструкция предназначена для установки и настройки готового пакета службы Prompribor OPC UA.
Если у вас еще нет файла Prompribor_OPC_UA_Service-x86_64.AppImage, обратитесь к разработчику.

1. Подготовка AppImage файла

chmod +x Prompribor_OPC_UA_Service-x86_64.AppImage
💡 Рекомендации для Linux:
  • Разместите файл в постоянной папке, например: /opt/prompribor/
  • Убедитесь, что у вас есть права на выполнение файла
  • Рекомендуется создать символическую ссылку: sudo ln -s /opt/prompribor/Prompribor_OPC_UA_Service-x86_64.AppImage /usr/local/bin/prompribor-service

2. Установка службы

./Prompribor_OPC_UA_Service-x86_64.AppImage -install
✅ Вы должны увидеть сообщение об успешной установке службы
⚠️ Если установка не удалась:
sudo ./Prompribor_OPC_UA_Service-x86_64.AppImage -install

3. Настройка конфигурации службы

📋 Файл конфигурации создается автоматически по пути:
~/.config/prompribor_opcua/settings.json

Создание папки конфигурации вручную:

mkdir -p ~/.config/prompribor_opcua

4. Настройка пути для логов

📝 Если logPath не указан в конфигурации, используются стандартные пути: Домашняя директория пользователя (/home/username/)

Рекомендуемые пути для логов:

sudo mkdir -p /var/log/prompribor
sudo chown $USER:$USER /var/log/prompribor
💡 Пример конфигурации для Linux:
"logPath": "/var/log/prompribor"

5. Запуск и управление службой

Способ 1: Через встроенные команды AppImage

./Prompribor_OPC_UA_Service-x86_64.AppImage -start
./Prompribor_OPC_UA_Service-x86_64.AppImage -stop
./Prompribor_OPC_UA_Service-x86_64.AppImage -restart
./Prompribor_OPC_UA_Service-x86_64.AppImage -uninstall

Способ 2: Через systemd

systemctl status prompribor_opcua_service
systemctl start prompribor_opcua_service
systemctl stop prompribor_opcua_service
systemctl enable prompribor_opcua_service
systemctl restart prompribor_opcua_service

6. Проверка работы службы

Проверка статуса службы:

./Prompribor_OPC_UA_Service-x86_64.AppImage --help
./Prompribor_OPC_UA_Service-x86_64.AppImage -v

Проверка логов:

tail -f /var/log/prompribor/service.log
journalctl -u prompribor_opcua_service -f

Проверка OPC UA сервера:

curl http://localhost:4840
netstat -tlnp | grep 4840

7. Устранение проблем

Если служба не запускается:

./Prompribor_OPC_UA_Service-x86_64.AppImage --debug

Если не хватает прав:

sudo ./Prompribor_OPC_UA_Service-x86_64.AppImage -start

Проверка занятости порта:

netstat -tlnp | grep 4840

Переустановка службы:

./Prompribor_OPC_UA_Service-x86_64.AppImage -uninstall
./Prompribor_OPC_UA_Service-x86_64.AppImage -install

8. Автозапуск службы

Для Linux (systemd):

systemctl enable prompribor_opcua_service

Для Linux (crontab):

crontab -e
Добавьте строку:
@reboot /full/path/to/Prompribor_OPC_UA_Service-x86_64.AppImage -start

Проверка автозапуска:

systemctl is-enabled prompribor_opcua_service
🎉 Служба успешно установлена и настроена!
Теперь вы можете подключиться к OPC UA серверу по адресу: opc.tcp://localhost:4840
📞 Если у вас возникли проблемы:
  • Проверьте правильность конфигурационного файла
  • Убедитесь, что порт 4840 не занят другим приложением
  • Проверьте логи службы для диагностики ошибок
  • Обратитесь к разработчику при необходимости
